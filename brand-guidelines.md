# Brand Guidelines — Personal Github Pages

> Generated with Brand Spec Sheet on 9/30/2026.

## The project

- **Name**: Personal Github Pages
- **Description**: Webapp with my personal github repository listing with super modern graphic and animation my projects and with short description. All list objects are linked with the github repository links
- **Target audience**: Github users
- **Sector**: Tech / Software
- **Mood**: Minimal

## Colors

| Role | Hex |
|---|---|
| Primary | `#0E1013` |
| Secondary | `#FAFAF9` |
| Accent | `#00A896` |
| Dark neutral | `#2C2F36` |
| Light neutral | `#DEE1E6` |

## Typography

- **Headings**: Outfit, weight 600
- **Body**: Hanken Grotesk, weight 400
- Keep body copy around 60–70 characters per line for readability.

## Tone of voice

`quiet` · `clean` · `confident` · `exact` · `orderly`

## Imagery & iconography

Studio-lit product shots on a single neutral background, one clear focal point per image, generous cropping. No busy backdrops or props that compete with the subject. Add clean product screenshots and abstract geometric illustrations to explain technical concepts.

## Spacing & grid

- **Base unit**: 8px
- **Scale**: 8px, 16px, 24px, 40px, 64px, 104px
- **Corner radius**: 2–4px
- A tight 8-column grid, consistent gutters, alignment used as the main decorative device.

## Logo — clear space

The logo sits alone on a flat field in at least 90% of applications. Never scale it non-proportionally or add effects.

## Do's and Don'ts

**Do:**
- Use consistent gutters everywhere
- Keep the accent for calls to action only
- Default to more white space, not less
- Show the real product (screenshots, UI) instead of abstract metaphors

**Avoid:**
- Round corners inconsistently across a page
- Add texture or noise overlays
- Use more than one weight per heading
- Rely on 3D isometric illustrations as a substitute for showing the real product
